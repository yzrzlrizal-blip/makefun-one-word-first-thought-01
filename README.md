One Word, First Thought — the first word that comes to mind, and nothing else: **petrichor**, the scent of rain on dry earth. A single vivid word: surprising, specific, and gone before a second draft could dull it.

## Run it

```sh
python3 main.py
```

The program writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when unset). Pure Python standard library, deterministic, no network, no randomness.
